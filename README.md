### Data Scientist and ML/AI Engineer in Copenhagen

I build machine learning and AI systems that run in production, from data pipelines and models to deployment, monitoring and evaluation. Physicist with a PhD and ten years of experience in atmospheric and acoustic simulation.

**Portfolio: [kjibran.github.io](https://kjibran.github.io)**

#### Projects

- [**Ask Statistics Denmark**](https://github.com/kjibran/statbank-rag-agent) answers questions about Denmark with official statistics, using hybrid RAG over 2,300 tables and LLM tool calling. [Live demo](https://huggingface.co/spaces/khajlk/ask-statistics-denmark)
- [**Copenhagen NO₂ forecast**](https://github.com/kjibran/mlops-air-quality-forecast) is a production-ready MLOps pipeline with automated retraining, drift monitoring and a public dashboard updated every hour. [Live dashboard](https://kjibran.github.io/mlops-air-quality-forecast/)
- [**LLM gateway**](https://github.com/kjibran/llm-gateway) is an OpenAI-compatible API with automatic failover across three LLM providers. [Live demo](https://huggingface.co/spaces/khajlk/llm-gateway-demo)
